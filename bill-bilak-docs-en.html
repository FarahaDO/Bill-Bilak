# Key Features & Highlights

Traditional browser zoom disrupts the entire responsive layout of pages. BilBilak solves this with an instant, on-demand magnification model:

🎯

Two Distinct Zoom Modes

Choose between Page Zoom (smoothly scales the page around your cursor) and Lens Mode (a circular floating magnifying glass tracking your mouse).

🖱️

Dynamic Mouse Wheel Zoom

Scroll your mouse wheel while holding your shortcut to fluidly scale between 1.1x and 8.0x on the fly with custom step intervals.

🎮

Arrow Keys Navigation

Need millimeter-level precision? While zoomed, nudge your focal point pixel-by-pixel using your keyboard arrow keys (↑ ↓ → ←).

🌫️

Focus Mode (Surrounding Blur)

Eliminate distractions by applying a configurable Gaussian blur to everything outside your magnified inspection area.

🗺️

DOM Canvas Mini-map

An intelligent, hardware-accelerated overview map in the corner of your screen indicating current viewport position across lengthy articles and docs.

🚫

Per-Site Blacklist

Disable the extension automatically on video streaming platforms (e.g. YouTube), web canvas games, or design tools with a simple domain manager.

# Installation Guide (Developer Mode)

BilBilak uses modern Manifest V3 and runs out-of-the-box without requiring any build tools, compilers, or external dependencies:

Open your terminal or command prompt and clone the repository:

BASH 
# Clone the project repository
git clone https://github.com/FarahaDO/Bill-Bilak.git

# Navigate into the extension folder
cd Bill-Bilak
  1. Visit the GitHub repository: FarahaDO/Bill-Bilak
  2. Click the green Code button and select Download ZIP.
  3. Extract the ZIP archive to a folder on your computer.

Enabling the Extension in Chrome / Edge / Brave:

  • Open Extension Manager
    Navigate to chrome://extensions in Chrome/Brave, or edge://extensions in Microsoft Edge.
  • Enable Developer Mode
    Toggle the Developer mode switch located in the top-right corner of the page.
  • Load Unpacked Extension
    Click the Load unpacked button and select the extracted Bill-Bilak folder.
  • Pin & Enjoy!
    The BilBilak otter icon 🦦 will appear in your browser toolbar. Pin it for quick access to settings.
💡 Browser Security Notice
For security reasons, web browsers prevent extensions from injecting content scripts into internal system tabs (such as chrome://, edge://, or the Chrome Web Store). Test BilBilak on any public website (e.g. Wikipedia, GitHub, or news sites).

# Zoom Modes Comparison

🔎 1. Page Zoom

Utilizes high-performance CSS transform: scale(...) with dynamic origin calculated from cursor coordinates:

  • Scales the entire webpage smoothly around cursor position.
  • Smooth CSS transitions with 150ms duration default.
  • Ideal for reading long-form articles, small typography, and documentation.
  • Includes cursor ring to maintain visual anchor.

🔍 2. Floating Lens Mode

A circular magnifying loupe tracking your cursor:

  • Only magnifies the area inside the circular lens; surrounding layout remains untouched.
  • Realistic glass reflections and 3D dropshadow.
  • Configurable radius from 80px to 300px.
  • Customizable border thickness and color picker.
  • Perfect for UI designers, photo inspection, and dense data tables.

# Site Blacklist Management

BilBilak provides a standalone options page (options.html) to manage excluded domains:

How Blacklisting Works:

When you register a domain like youtube.com or figma.com, BilBilak checks window.location.hostname before activating. If matched, the extension remains completely passive with zero CPU or memory footprint.

✅ Automatic wildcard subdomain matching (e.g. en.wikipedia.org matches wikipedia.org) 💾 Persisted across devices via chrome.storage.sync
JAVASCRIPT (Blacklist check logic in content.js) 
function isBlacklisted() {
  const hostname = window.location.hostname;
  return settings.blacklist.some(domain => hostname.includes(domain));
}

# Real-Time Settings Synchronization

Every content script tab registers a listener on chrome.storage.onChanged. Changing any option in the popup immediately takes effect across all open tabs without requiring a page reload:

JAVASCRIPT 
chrome.storage.onChanged.addListener((changes) => {
  for (const key in changes) {
    settings[key] = changes[key].newValue;
  }
  if (isBlacklisted()) settings.enabled = false;
  if (!settings.enabled && isZoomed) resetZoom();
  updateVisuals();
});

# Frequently Asked Questions (FAQ)

Does BilBilak collect or store any personal browsing data? ▼
No, absolutely not. BilBilak is built with privacy as a foundational principle. It makes zero outbound network requests, contains no third-party trackers or telemetry, and executes 100% locally within your browser sandbox.
Why doesn't the zoom activate on certain tabs? ▼
Chromium security policies restrict all extensions from running content scripts on internal browser URLs (e.g., chrome://settings or the Chrome Web Store). Also ensure the active domain has not been added to your Blacklist in the Options page.
Do my custom shortcuts and lens settings sync across computers? ▼
Yes! BilBilak uses chrome.storage.sync. As long as you are signed into your browser profile, all your preferences seamlessly sync across your desktop, laptop, and workstations.
How can I contribute or report an issue? ▼
The project is fully open source under the MIT License. You can open an issue or submit a pull request directly on the official GitHub Repository.
