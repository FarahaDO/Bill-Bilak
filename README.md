## 🇬🇧 English

### 📖 About

**BilBilak** is a lightweight, privacy-focused, multilingual browser extension that provides instant zoom functionality on any webpage. Simply hold your configured keyboard shortcut and the area under your cursor will be magnified — perfect for reading small text, inspecting details, or accessibility needs.

### ✨ Features

- 🌐 **Multilingual Support**
  - English and Persian (فارسی) built-in
  - In-app language switcher (no browser restart needed)
  - Automatic RTL/LTR detection based on language
  - Easy to add new languages (just edit `i18n.js`)
- 🎯 **Two Zoom Modes**
  - **Page Zoom**: Zooms the entire page around the cursor
  - **Lens Mode**: Floating magnifier lens that follows your cursor
- ⌨️ **Customizable Shortcuts**: Set your own keyboard combination
- 🖱️ **Mouse Wheel Zoom**: Adjust zoom level on-the-fly with scroll wheel
- 🎮 **Keyboard Navigation**: Move the zoom point with arrow keys
- 🎨 **Customizable Appearance**: Change lens size, border color, and more
- 🌫️ **Focus Mode**: Blurs surrounding content for better concentration
- 🗺️ **Mini-map**: Small overview of the page in the corner
- 🚫 **Site Blacklist**: Disable the extension on specific websites
- 💾 **Sync Settings**: Your preferences sync across all devices
- 🎬 **Smooth Animations**: Beautiful transitions for a polished experience
- 🔒 **Privacy First**: No data collection, everything runs locally
